# BTN4 – Mô phỏng TZ4L-R4S và lò nhiệt

Trang tĩnh (static), không cần build.

## Deploy lên Vercel
**Cách 1 – Kéo thả/GitHub:** push thư mục này lên GitHub → vercel.com → Add New Project → Import → Framework Preset: **Other** → Deploy (để trống Build Command và Output Directory).

**Cách 2 – CLI:**
```
npm i -g vercel
vercel --prod
```
